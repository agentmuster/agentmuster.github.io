Your agents' history and your work queue, in one place.

Muster indexes every Claude Code, Codex and Pi session on your computer, so you can find what was decided last week and carry on from there. The Teams requests and pull requests waiting on you sit beside them. New work runs through Pi, and all of it works from your phone.

Install View on GitHub

Free and open source (MIT). Runs on your Mac; Linux is untested.

Every session you've had, searchable

Muster reads the session files Claude Code, Codex and Pi already keep and builds a search index on your computer.

Find the right one

Search by ticket, repository or topic. Or describe the task, and a short Pi run searches for you and reports up to five sessions, why each fits and where it stopped.

Carry on where it stopped

Continue a Pi session in place, or split any session into a new Pi thread. Claude Code and Codex conversations come along as cited context.

Context in every new thread

Before the first reply, Muster picks up to three earlier sessions that match the task and sends excerpts with their file paths. A session that names the exact ticket always wins.

Your agents can look too

Install the included Pi package and Pi gets tools to search and read your earlier sessions, in Muster or in any terminal.

The work waiting for you, beside it

Modules bring work in from the tools you already use. Install them from the app, or write your own in TypeScript.

When the agent needs you

Runs keep going when you close the tab. With BrowserOS, an agent that hits a sign-in or a CAPTCHA pauses and hands you its browser on whatever device you're holding, and a menu-bar app for the Mac tells you when a thread is waiting.

On your computer

Muster, the index and your threads stay on your machine. There's no Muster account or server. Model requests go to the provider you set up in Pi.

From your phone

Reach it through a tunnel you control, such as a free Cloudflare quick tunnel, and add it to your Home Screen. How

Open source

MIT licensed. The app and its modules are on GitHub.

Install

curl -fsSL https://agentmuster.io/install.sh | bash

You need macOS, git, Node 22.23 or later, Python 3.9 or later, and the Pi CLI signed in to a model provider. The installer checks for them first and tells you what's missing; it doesn't install them for you.

It sets Muster up in ~/.muster, starts it at login and prints the address, http://127.0.0.1:47831. Run it again to update. The script is on GitHub if you'd like to read it first, and the README covers sign-in, remote access and modules.

Write a module

A module is a folder with a manifest and a TypeScript file. It can add actions with a preview, Inbox feeds, tools for the agent, or a pull-request provider for your code host. Start from the template in muster-modules.
