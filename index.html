All your coding agents, in one place.

Muster is a web app for Pi agents that runs on your own computer. Every Pi, Claude Code and Codex session you've had becomes something your agents can search and build on, and you can reach all of it from your phone, wherever you are.

View on GitHub Install

MIT licensed. Early days: macOS first.

01

Everything runs locally

Muster, your sessions and their search index stay on your computer. It listens only on your own machine, and there's no Muster server or account. Model requests go to the provider you set up in Pi.

02

Every session at your agent's disposal

Muster indexes all your Pi, Claude Code and Codex sessions. It hands the relevant ones to a new thread as cited context, your agents can search them while they work, and you can continue or branch any of them.

03

Built for Pi, reachable from anywhere

Threads run through Pi with your own models, extensions, skills, subagents and workflows. Reach Muster from your phone through a tunnel you control; it installs as an app.

04

An interface you can extend

Modules add to the app itself: actions with a preview, Inbox feeds, tools for the agent, and review panels. Browse and install them in the app, or write your own in TypeScript.

05

Open source, MIT

Free to use, change and ship. The app and its modules are on GitHub.

Review and merge in the session

When the agent opens a pull request, read the diff file by file, mark it reviewed and merge, without opening your code host. Your sign-off is pinned to the exact commits, so a later push needs another look. Bitbucket today.

Teams requests in one Inbox

Teams messages meant for you are grouped into requests, each with what someone needs and the messages behind it. Thanks and FYIs stay out of the way. Start a session from any request.

Stay in the loop on your phone

Queue messages, follow background subagents and workflows, answer the agent's questions, and get a notification when a reply is ready. A terminal is there when you need one.

Take over the browser

With BrowserOS, when the agent hits a sign-in, a one-time code or a CAPTCHA, it pauses and hands you its browser, live, on whatever device you're holding.

Install

curl -fsSL https://agentmuster.io/install.sh | bash

You need macOS, git, Node 22.23 or later, Python 3.9 or later, and the Pi CLI signed in to a model provider. The installer checks for them first and tells you what's missing; it doesn't install them for you.

It sets Muster up in ~/.muster, starts it at login and prints the address, http://127.0.0.1:47831. Run it again to update. The script is on GitHub if you'd like to read it first, and the README covers sign-in, remote access and modules.

Write a module

A module is a folder with a manifest and a TypeScript file. It can add actions with a preview, Inbox feeds, tools for the agent, or a pull-request provider for your code host. Start from the template in muster-modules.
